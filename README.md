# Спорт-таймер

Интервальный таймер для телефона: раунды, табата, EMOM, AMRAP, обратный отсчёт, конструктор цепочек, секундомер с кругами.
Работает без интернета после первой загрузки. Данные хранятся только на телефоне.

## Как выложить на GitHub Pages

1. Создайте на github.com новый репозиторий, например `timer` (Public).
2. Нажмите **Add file → Upload files** и перетащите **все файлы и папки** из архива
   (`index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, папки `icons`, `sounds`, `fonts`). Нажмите **Commit changes**.
3. **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты адрес появится вверху той же страницы: `https://ВАШ-ЛОГИН.github.io/timer/`.

## Установка на телефон

1. Откройте адрес в **Chrome**.
2. Меню ⋮ → **Добавить на главный экран** → **Установить**.
3. Запускайте с иконки — откроется как обычное приложение, без адресной строки.

## Обновление

Замените файлы в репозитории и в `sw.js` увеличьте номер в строке `CACHE = 'sport-timer-v1.0.1'`
(например, на `v1.0.2`). При следующем запуске приложение предложит обновиться.

## Резервная копия

Настройки → Данные → «Отправить копию» → выберите Яндекс Диск.
Восстановление: «Загрузить из файла» → выберите файл `.json`.
